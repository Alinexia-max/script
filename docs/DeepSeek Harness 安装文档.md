本文档包含 DeepSeek Harness 桌面版（Windows / macOS）的安装说明，以及 `dsh-market` 插件市场的启用指南。

## 1. Windows 安装

适用于 Windows 10 / Windows 11 桌面版。

### 1.1 获取安装包

安装包由网盘直接提供，无需在线下载。

- 文件名形如：`dsh-latest-windows-x64.exe

### 1.2 安装

1. 双击安装包启动安装向导。
2. 若弹出“用户账户控制”提示，点击 **是**。
3. 选择安装目录（默认路径：`C:\Program Files\DeepSeek Harness`）。
4. 勾选 **创建桌面快捷方式**（可选）。
5. 点击 **安装**，等待进度完成。
6. 点击 **完成** 退出向导。

### 1.3 首次启动

1. 双击桌面快捷方式，或从开始菜单搜索 `DeepSeek Harness` 启动。
2. 若出现 Windows Defender SmartScreen 的“已保护你的电脑”提示：
   - 点击 **更多信息**，再点击 **仍要运行**。
3. 按界面引导完成初始化 / 登录。

### 1.4 验证安装

- 开始菜单中能找到并正常打开 `DeepSeek Harness`。

### 1.5 常见问题

| 现象 | 可能原因 | 解决方法 |
|---|---|---|
| 安装被 SmartScreen 拦截 | 安装包未签名或为新发布版本 | 点击“更多信息”→“仍要运行” |
| 双击安装包无反应 | 安装未完成或权限不足 | 右键安装包 → 以管理员身份运行 |
| 杀毒软件提示风险 | 误报 | 将该安装包 / 安装目录加入信任白名单 |
| 启动后白屏或闪退 | 显卡驱动或运行库缺失 | 更新显卡驱动，重启后重试 |

### 1.6 卸载

设置 → 应用 → 已安装的应用 → 找到 `DeepSeek Harness` → 卸载。

## 2. macOS 安装

适用于 macOS 桌面版。

### 2.1 获取安装包

安装包由交付方直接提供，无需在线下载。

- 文件名形如：`dsh-latest-macos-arm64.dmg`（Apple Silicon）

### 2.2 安装

1. 双击 `.dmg` 文件，等待磁盘映像挂载。
2. 在打开的窗口中，将 **DeepSeek Harness** 图标拖拽到 **Applications** 文件夹。
3. 在访达侧边栏点击弹出按钮，推出该磁盘映像。
4. 打开 **启动台** 或 **应用程序** 文件夹，双击 `DeepSeek Harness`。

### 2.3 首次启动放行

首次打开可能被系统安全策略拦截，按提示处理：

- 提示“无法打开，因为来自身份不明的开发者”：
  系统设置 → 隐私与安全性 → 在底部点击 **仍要打开**。
- 提示“已损坏，无法打开，你应该将它移到废纸篓”：
  打开终端执行以下命令后重新打开：

  ```bash
  sudo xattr -cr /Applications/DeepSeek\ Harness.app
  ```

### 2.4 验证安装

- 应用程序文件夹中存在 `DeepSeek Harness`，且可正常启动。

### 2.5 常见问题

| 现象 | 可能原因 | 解决方法 |
|---|---|---|
| 提示“已损坏，无法打开” | 隔离属性被附加 | 执行 `sudo xattr -cr /Applications/DeepSeek\ Harness.app` |
| 提示“身份不明的开发者” | 未完成公证 | 系统设置 → 隐私与安全性 → 仍要打开 |
| 安装包芯片不匹配 | 下载了错误的架构 | 按“关于本机”确认芯片后更换安装包 |
| 启动后无响应 | 系统版本过低 | 【待补充】最低 macOS 版本要求 |

### 2.6 卸载

将 `应用程序` 中的 `DeepSeek Harness` 拖入废纸篓，并清空。
